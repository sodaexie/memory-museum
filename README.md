# 记忆博物馆

在本机写日记、查往事、留下自己确认过的经验。可以用本机 Ollama 或自己配置的 API 提取事件、人物和标签。页面会显示相关旧事及可点开的原文。模型有足够依据时会给一条简短建议。

## 先试示例

在本项目目录的终端运行：

```bash
python3 app.py --demo --port 8769 --open
```

打开「心路历程」，看看关于小 A 改约的几条虚构记录。点「提炼选中记录」可以查看前后想法的变化和来源。也可以在写日记页填入示例，试试从新日记进入回看。示例模式使用虚构日记和模拟结果，写入独立的临时目录，退出后清理。

## 开始写自己的日记

在本项目目录的终端运行：

```bash
python3 app.py --open
```

页面地址是 `http://127.0.0.1:8765`。关闭浏览器后，程序继续在该终端运行。按 Control+C 停止。需要 Python 3.10 或更新版本，使用 Python 标准库。模型未连接时，可以照常写日记、手动改标签和检索原文。

写日记时可以添加本机的 JPG、PNG、GIF 或 WebP 图片，也可以粘贴网址或带网址的帖子分享文字。只有图片或链接也能保存。每条可加 6 张图片（单张最多 5 MB，合计最多 15 MB）和 6 个链接。原文页可以打开大图和帖子地址。「翻阅往事」的「全部」范围也能按网址或域名搜索。链接只记录地址，点击时才打开。AI 整理仍使用日记正文和相关文字摘录。

## 在页面里连接模型

打开侧栏的「模型设置」。

- **Ollama** 使用你的本机模型。安装并打开 [Ollama for macOS](https://docs.ollama.com/macos)，运行 `ollama pull qwen3:4b`，或选择已经下载的其他模型。记忆博物馆使用本机地址 `127.0.0.1:11434`。
- **OpenAI** 填入你自己的 API Key 和账号有权使用的模型名称。默认预填 `gpt-6-luna`，调用 OpenAI 官方 Responses API。
- **自定义 API** 填入服务商的基础地址、模型名称和 API Key。兼容接口需支持 Chat Completions 的 JSON 模式。远程地址使用 HTTPS。

「测试连接」只发固定示例。点「保存设置」后立即生效。选 API 时，默认在用户手动点「用 AI 整理」或「提炼选中记录」时发起请求。可以在设置中开启保存日记后自动整理。使用 API 时，当次分析用到的日记和摘录会发送给所选服务。

API Key 保存在数据目录下仅当前系统用户可读写的 `.model-settings.json` 文件。Git 默认忽略这个文件。需要时从页面点击「删除已存 Key」。启动时的 `--model` 可指定首次使用的 Ollama 模型。

## 回看一件事

在「心路历程」输入关键词或事件主题，关联人物可选。找到的日记按日期排开，每条都能打开原文。可以勾选其中 2–8 条，用所选模型提炼当时的想法、感受、想采取的行动和之后的反思。每个摘录的内容都来自对应日记。模型有两条以上来源支撑时，会给一句关于前后变化的概括。

「心路历程」首页的「成长足迹」会从最近 14 天内最多 12 条文字日记的摘录中找值得回看的时刻。围绕同一件事的记录按日期连成时间线，同一天的多个高光各自保留出处。本机模型就绪时打开页面会自动整理。使用远程 API 时，点击「用 API 整理」才会发送近期摘录。示例模式可以查看虚构的秋招足迹。

## 沿着关键词找关联

在「关键词关联图」，人物、主题和标签是节点。同一事件摘录里一起出现的节点之间会连线。手动标签按整条日记关联。线条的粗细反映共同出现过的日记数量，可以点开任意节点或连线查看出处。图中一次最多显示 24 个节点，可以搜索任意已记录的关键词，查看它的关联，再跳到对应的「心路历程」。

## 本机数据

新存档默认保存在 `~/Library/Application Support/记忆博物馆`。已有「心迹」或「日记管家」存档时，程序会继续读写原目录。用 Finder 的「前往文件夹」可打开，也可以用 `--data-dir` 在启动时指定本地目录。备份完整日记时请一并备份以下目录。

- **日记**存储按日期命名的 Markdown 原文。
- **整理**存储摘要、原文引句、标签和建议。详情页可改人物和自定义主题标签。
- **记忆**存储在「关于我」写下的偏好、边界和经验。可关联一条或多条日记，也可编辑或删除。关联来源与当前事件相近时，管家会优先参考这条记忆。
- **附件**存储与各条日记对应的图片副本和链接。

页面通过本机地址访问。关联图、时间线的搜索和日记存档都在本机。当前按人物、标签、原文和内置的主题同义词找旧事，建议基于已找到的来源。写完时的回看在页面内显示。
